# TDP-43 Explainers

Short (2–3 minute) plain-English video explainers of recent ALS and TDP-43 research papers, one per night.

Each dated folder contains:
- `video.mp4` — narrated slide video
- `script.md` — the full narration script
- `paper.md` — citation and links to the original paper

These are educational summaries, not medical advice. Always read the original paper and talk to your care team.
